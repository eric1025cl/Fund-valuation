# Fund Valuation

中国公募基金盘中估值 MVP。后端通过可选 AKShare 数据源读取官方估值、净值、持仓和 A 股行情；官方估值缺失时按披露持仓和实时行情做覆盖率归一化估算。

## 启动

```powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。

## 测试

```powershell
python -m unittest discover -s tests -v
```

## 估值口径

```text
估算涨跌 = Σ(持仓权重 × 标的实时涨跌) / 已覆盖持仓权重
估算净值 = 最新官方单位净值 × (1 + 估算涨跌)
```

估值结果会带 `trade_date` 标明数据所属交易日。页面在交易日 9:00-15:05 每 10 分钟自动刷新。非交易日优先使用上一交易日 15:00 估值快照，没有快照则重新计算；交易日 9:00 前按上一交易日收盘后的数据归属；交易日 15:00 后按当日收盘后数据归属；每个交易日 15:05 自动保存收盘估值快照。

如果目标交易日的官方单位净值已经发布，服务会直接使用该净值作为最终估值，避免在非交易日或收盘后重复套用同一交易日行情涨跌。快照对账拿到实际净值后，会回填 `actual_nav`、`actual_growth_pct` 和误差字段到快照明细；持仓穿透估值会在样本充足时按历史对账均值误差做轻量偏差修正。

后台任务会定期重试未对账快照；如果首次回填时净值尚未发布，会保留该快照并在后续重试中自动补齐。

估算结果仅供研究和看板参考，不构成投资建议。
